# TradeQuote V2 estimating audit | 24 October 2026

Status: REVIEW ONLY. Public main and the production site are unchanged.

Confirmed by direct evaluation of current calculation logic:

1. Rectangular patio 5 m x 4 m with 600 mm square paving units: 9 columns x 7 rows = 63 units before cutting allowance when following a simple full-unit grid. Existing area-only algorithm returned 62 with 10% area allowance, below this basic grid; it must not be treated as a reliable bill of quantities.
2. Patio 4.2 m x 1.8 m: area 7.56 square metres, existing method returns 24 units using 10% allowance. This is a synthetic example, not a site-specific bill of quantities.
3. Completed-job cost variance must not be shown until all six actual expense categories have been explicitly entered. The current version can show a variance from partial cost data.
4. Actual direct expenditure should be compared to modelled direct cost, not a cost value including contingency and overhead. History archives need an explicit comparable cost-basis marker so legacy records are not mixed.
5. The customer quote must remain blocked for pending site checks and price-source evidence; unapproved variations must not enter agreed revenue.

Not verified: current supplier prices in Oxfordshire, real completed job costs, authorised completed-job data, mobile browser UI and PDF export, competitor timed comparisons, customer value.
